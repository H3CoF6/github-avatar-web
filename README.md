# 🌌 GitHub Identicon Decoder

A high-performance web application to reverse-engineer GitHub default avatars (Identicons) back to their original User IDs using client-side WebAssembly and multi-core brute-forcing.

## ✨ Features

- **⚡ Blazing Fast Brute-Force**: Scans over 210 million IDs in seconds by leveraging Rust-compiled WebAssembly and multi-threaded Web Workers.
- **🎨 Visual Recognition**: Automatically extracts the 5x5 symmetry grid and HSL color data from uploaded screenshots.
- **💎 Vercel Vibe UI**: Sleek, minimalistic design with smooth Framer Motion animations and support for both Light and Dark modes.
- **📊 Rich User Data**: Fetches real-time GitHub profiles and displays official contribution stats for matched users.
- **🌗 Smart Categorization**: Displays results in two columns: "Default Avatars" (matching the target) and "Customized Avatars" (users who once had this ID but changed their picture).

## 🛠️ Development

### Prerequisites

- Node.js 20+
- Rust & `wasm-pack`

### Getting Started

1. **Build the WASM module**:
   ```bash
   cd wasm-bruteforcer
   wasm-pack build --target web
   ```

2. **Setup the frontend**:
   ```bash
   cd ..
   npm install
   # Copy WASM to public
   mkdir -p public/wasm
   cp wasm-bruteforcer/pkg/*.wasm public/wasm/
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

## 📖 How it Works

GitHub's identicons are generated by taking the MD5 hash of the user's numeric ID. The first 15 nibbles determine the 5x5 grid (since it's vertically symmetrical), and the last few bytes determine the HSL color.

This tool performs the inverse operation:
1. It extracts the target grid and color from your image.
2. It spawns $N$ Web Workers (one per CPU core).
3. Each worker runs highly optimized Rust code to hash IDs from `0` to `~210,000,000`.
4. When a hash matches the pattern and color, the ID is returned to the UI.
